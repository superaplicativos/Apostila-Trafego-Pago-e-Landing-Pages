# Apostila de Tráfego Pago & Landing Pages

Material educacional completo (nível intermediário→avançado) para mentorados em tráfego pago:

- **Google Ads** — Search, Performance Max, Demand Gen, AI Max (2025), lances inteligentes, scripts
- **Meta Ads** — Gerenciador de Anúncios, Advantage+, Pixel + CAPI, click-to-WhatsApp
- **Testes A/B** — metodologia científica e significância estatística
- **Landing Pages** — anatomia, copywriting, checklist de QA e modelos por nicho
- **Vibe Coding** — landing pages com IA (z.ai · GLM-5.3)
- **GitHub** — token fine-grained, deploy automático e GitHub Pages grátis
- **Carreira** — portfólio, cases, currículo, certificações e simulado de entrevista

## Acessar a apostila

Site publicado no GitHub Pages:

**https://superaplicativos.github.io/Apostila-Trafego-Pago-e-Landing-Pages/**

## Estrutura

```
├── index.html   # apostila completa (10 módulos + extras)
├── styles.css   # design system (tema dark premium)
├── app.js       # navegação, scrollspy, glossário com busca, impressão
└── .nojekyll    # serve os arquivos como estão
```

## Como atualizar

1. Edite `index.html`, `styles.css` ou `app.js`
2. Faça commit na branch `main`
3. O GitHub Pages republica automaticamente em segundos

Dica: o site pode ser impresso em PDF pelo botão "Imprimir / salvar em PDF" (tema claro otimizado para papel).
